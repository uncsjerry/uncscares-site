3. How the Donation Flow Works

  1. Donor clicks "Donate" on the website and selects an amount and fund
  2. Stripe Checkout opens — donor enters card info on Stripe's secure page
  3. Payment completes — donor sees the "Thank You" success page
  4. Stripe fires a webhook to the site automatically
  5. Webhook handler records the donation in Supabase (donors + donations tables)
  6. Receipt email is sent to the donor from receipts@uncscares.org via Resend

All of this happens automatically. No manual steps required.

4. Contact Form Submissions

When someone submits the contact form at uncscares.org/contact, an email is sent to support@uncscares.org with their name, email, subject, and message. The reply-to is set to the sender's email, so you can reply directly.

Contact form emails are also visible in the Resend dashboard.

5. Before Accepting Real Donations

Action Required: Stripe is currently in test mode. Real credit cards will not be charged. Complete these steps to go live:

  1. Stripe Dashboard: Activate your account (complete identity verification if prompted)
  2. Stripe Dashboard: Switch to Live mode (toggle in top-right)
  3. Stripe Dashboard: Copy your live secret key (starts with sk_live_ or rk_live_)
  4. Stripe Dashboard: Create a new webhook endpoint in live mode for https://uncscares.org/api/webhooks/stripe — copy the new signing secret
  5. Vercel Dashboard: Settings > Environment Variables — update:
    • STRIPE_SECRET_KEY → your live key
    • STRIPE_WEBHOOK_SECRET → your new live webhook signing secret
  6. Vercel Dashboard: Redeploy the site (Deployments > click latest > Redeploy)

7. Quick Troubleshooting

Problem Where to Look
Donation not recorded in Supabase Stripe Dashboard > Developers > Webhooks > check delivery logs
Receipt email not sent Supabase donations table — check receipt_sent column. Also check Resend dashboard.
Site not updating after code push Vercel Dashboard > Deployments — confirm latest deploy succeeded
Contact form not working Check Resend dashboard for delivery errors. Verify RESEND_API_KEY in Vercel env vars.
